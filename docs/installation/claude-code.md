# Claude Code

Layout: `.claude/skills/<nome>/SKILL.md`, `.claude/agents/<nome>.md`
(projeto) ou `~/.claude/` (user scope).

```bash
data-sentinel install --host claude --yes
```

Instala 5 skills + 3 agents em Markdown. O bloco gerenciado vai para
`CLAUDE.md` e `AGENTS.md`. MCP via `.mcp.json` do projeto.
