## Implementation discovery (ds-0101 → ds-0103 verified)

- ~~Backend SSE stream does not emit `id:` frames~~ — **false**: `stream()` emits
  `id: {seq}` on replay and live frames (verified ds-0103). `Last-Event-ID`
  replay is real. What ds-0103 *did* fix: per-subscriber queue fan-out (shared
  queue split events between concurrent clients) and a replay/subscribe gap
  (subscribe-before-replay + seq dedupe).
- 401 responses carry no issued-at/expiry metadata; session TTL tracked
  client-side only (acceptable per ADR-0014; `WWW-Authenticate: Bearer` added
  in ds-0103).
